03 / Agent versus material · eight-seed experiment

Who judges the shore?

A passive wave changes its bed. An agent can instead try a small material change, measure what happened at the harbour, and undo the change if it was worse. Run 200 candidate changes for each of eight fixed beds, and see how strongly the proposal's shape matters.

This is not self-learning sand. Every accepted update requires a global better/worse measurement and the power to reverse unsuccessful changes. The medium is a synthetic 48-site steady-state wave operator, not Claude's 2D coastal model, not the original finite-difference shore, and not a real physical experiment. No numerical adjoint or teacher is used by these agent arms.

Benchmark controls

Fixed seeds: 1001, 1009, 1013, 1019, 1021, 1031, 1033, 1039. Both targets · five proposal families · 200 trials each. Click Run.

Objective = receiver power |u|²: quiet means lower power (negative dB); loud means higher power (positive dB). Each candidate is actually evaluated using the changed wave operator. Improvement is monotonic under the acceptance rule by construction; that is an agent property, not a physical-learning law.

What this tests—and what it cannot tell us

The test directly addresses Claude's new G8 result: trial learning can work with loss because it evaluates performance after changing the medium, instead of asking a dissipative backward wave to carry an adjoint gradient. But the system gets a privileged agent, a receiver objective, and perfect restoration of rejected material changes. The original Memory Drift lab separately compares a privileged, bed-frozen stress reset against an active teacher-free rest that itself moves the bed.

Read the protocol in SITE_G9_PROTOCOL.md. The eight seeds and candidate families are frozen for reproducibility, and all results are synthetic browser calculations. They must not be described as a direct replication of ComputingBeachClaude or as evidence of autonomous sediment optimization.
